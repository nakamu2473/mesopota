# mesopota

楔形文字を書ける・学べる Web アプリ。

## 機能

- **習字モード** (`/practice`) — お手本の楔形文字をなぞって練習（楔単位のガイド・採点・進捗保存）
- **自由書きモード** (`/canvas`) — キャンバスに自由に楔形文字を書いて PNG 保存
- **読み取りモード** (`/read`) — 書いた楔形文字を認識して読み・意味を表示
- **変換モード** (`/convert`) — 日本語（かな）を楔形文字の音節文字に音写

書く操作はすべて「ドラッグ＝楔を 1 本打つ／タップ＝ウィンケルハーケン」の楔スタンプ入力です。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト（vitest）
npm run build    # 型チェック + ビルド
```

### 文字データの追加

`src/data/signs.json` に楔分解データ（`wedges`）を追記すると、その文字が習字・読み取りの対象になります。
自由書きモードの「JSONコピー」で、描いた楔をそのままデータとして書き出せます。
