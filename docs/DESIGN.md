# mesopota — 楔形文字アプリ 設計書

## 1. 概要

楔形文字（シュメール・アッカド楔形文字）を「書く・練習する・読み取る・変換する」ための Web アプリケーション。

### 機能一覧

| # | 機能 | 概要 |
|---|------|------|
| F1 | 習字モード | お手本の楔形文字をなぞって練習。楔（ウェッジ）単位でガイド表示・採点 |
| F2 | 自由書きモード | キャンバスに自由に楔形文字を書く。画像として保存・共有 |
| F3 | 読み取りモード | 書いた楔形文字を認識し、文字名・読み・意味を表示 |
| F4 | 変換モード | 日本語（かな）を楔形文字の音節文字に変換して表示 |

## 2. 基本方針・技術選定

| 項目 | 選定 | 理由 |
|------|------|------|
| プラットフォーム | Web（PWA 対応） | PC・スマホ・タブレット両対応。タッチでの書き心地重視 |
| フレームワーク | React + TypeScript + Vite | 標準的でツール群が充実 |
| 描画 | SVG（表示・ガイド） + Pointer Events（入力） | 楔はベクタ図形として定義するので SVG が自然。拡大しても劣化しない |
| 状態管理 | React 標準（useState / useReducer + Context） | MVP には十分。必要になったら Zustand 等を検討 |
| データ永続化 | localStorage（学習進捗） | バックエンド不要。全機能クライアントサイドで完結 |
| フォント | Noto Sans Cuneiform（変換モードの表示用） | Unicode 楔形文字ブロック（U+12000–U+123FF）をカバー |
| テスト | Vitest + React Testing Library | 認識・変換ロジックはユニットテストしやすい純関数に切り出す |

**バックエンドは持たない。** 文字データは静的 JSON としてバンドルし、進捗は localStorage に保存する。将来的にランキングや ML 認識を入れる場合にのみ API を検討する。

## 3. 中核となる考え方：「楔（ウェッジ）」モデル

楔形文字は筆画（ストローク）ではなく、葦のスタイラスを粘土に**押し付けた楔の集合**でできている。本アプリでは文字を「楔の並び」としてモデル化する。これが習字・自由書き・読み取りすべての土台になる。

### 3.1 楔の種類

| 種類 | 記号 | 説明 |
|------|------|------|
| 横楔 | `H` | 左に頭、右に尾を引く水平の楔 |
| 縦楔 | `V` | 上に頭、下に尾を引く垂直の楔 |
| 斜め楔 | `D` | 任意角度の楔（角度パラメータで表現） |
| ウィンケルハーケン | `W` | 頭だけの「くの字」型。尾を引かない |

### 3.2 データ構造

```ts
/** 1本の楔。文字ローカル座標系（0–100 の正方形）で定義 */
interface Wedge {
  type: 'H' | 'V' | 'D' | 'W';
  x: number;        // 頭（打点）の位置
  y: number;
  length: number;   // 尾の長さ（W は 0）
  angle: number;    // 尾の方向（度）。H=0, V=90 を基準に D で任意値
}

/** 1文字分の定義 */
interface Sign {
  id: string;             // 例: "KA"
  codepoint: string;      // 例: "U+12157"（フォント表示用）
  name: string;           // 文字名
  values: string[];       // 音価（読み）例: ["ka"]
  meaning?: string;       // 意味（表語文字の場合）例: "口"
  wedges: Wedge[];        // 楔の並び（書き順 = 配列順）
  level: 1 | 2 | 3;       // 難易度（楔の本数目安: ~4 / ~8 / それ以上）
}
```

- `src/data/signs.json` に格納。**書き順**は「横→縦、左→右、上→下」という実際の刻字慣行に従って配列順で表現する。
- 楔の描画は共通コンポーネント `<WedgeGlyph>` が担当し、`Wedge` → SVG パス（三角形の頭＋細くなる尾）に変換する。

### 3.3 収録文字（段階的に拡充）

1. **第1弾（約60字）**: 日本語変換に必要な CV 音節（ka, ki, ku, ke, ko, sa, si, su, ... , a, i, u, e）+ 有名な表語文字（AN 𒀭, KI 𒆠, LUGAL 𒈗 など）
2. **第2弾（約150字）**: VC 音節（ab, ib, ub, an, in, un, ...）、頻出表語文字
3. **第3弾**: 数字（U+12400 ブロック）、その他

楔分解データは既存データベースがないため自作する。フォントグリフを下敷きに楔を配置するデータ作成用の**内部エディタ**（自由書きモードの流用）を最初に作り、データ整備を効率化する。

## 4. 入力方式：楔スタンプ入力

指やマウスで「線をなぞる」のではなく、**ドラッグ＝楔を1本打つ**という入力方式を採用する。

- **ドラッグ**: 始点＝楔の頭、ドラッグ方向と距離＝尾の向きと長さ。離した時点で楔が確定
- **タップ**: ウィンケルハーケン（W）を打つ
- ドラッグ角度から `H` / `V` / `D` を自動判定（±20° 以内なら H/V にスナップ。設定でスナップ解除可）

この方式の利点:
- 実際の楔形文字の筆記（スタイラスの押印）に近い体験になる
- ユーザー入力が最初から `Wedge[]` という構造化データになるため、**なぞり判定・読み取り認識が画像処理なしで実現できる**

フリーハンド描画（本当に自由な線）は自由書きモードのオプションとして残すが、読み取り対象は楔スタンプ入力のみとする（MVP）。

## 5. 各機能の設計

### 5.1 F1: 習字モード（なぞって練習）

**フロー**: 文字一覧（レベル別）→ 練習画面 → 採点 → 進捗保存

**練習画面**:
1. お手本の文字を薄いグレーで表示
2. 次に打つべき楔をハイライト（頭の位置に「ここから」マーカー＋尾方向の矢印）
3. ユーザーが楔を打つと判定:
   - 頭の位置誤差（正規化距離）
   - 角度誤差
   - 長さ誤差
4. 合格なら次の楔へ。3回失敗でアニメーションによるお手本再生
5. 全楔完了で総合スコア（0–100）を表示

**判定関数**（純関数として実装・テスト対象）:

```ts
function scoreWedge(input: Wedge, target: Wedge): {
  ok: boolean; score: number;
  feedback: 'position' | 'angle' | 'length' | null;
}
```

**進捗データ（localStorage）**:

```ts
interface Progress {
  [signId: string]: {
    bestScore: number;
    attempts: number;
    lastPracticed: string; // ISO date
    mastered: boolean;     // score >= 80 を3回
  };
}
```

### 5.2 F2: 自由書きモード

- 広いキャンバス（パン・ズーム可）に楔スタンプ入力で自由に書く
- ツール: 楔サイズ変更 / 取り消し・やり直し / 全消去 / フリーハンドペン（オプション）
- 出力: PNG エクスポート（SVG → canvas 変換）、端末保存・Web Share API で共有
- 書いた内容（`Wedge[]`）はそのまま読み取りモードに渡せる（「これ何て読む？」ボタン）

### 5.3 F3: 読み取りモード

書かれた楔の集合から文字を同定する。**MVP は機械学習を使わず、楔データ同士のマッチング**で実現する。

**アルゴリズム**:
1. 入力 `Wedge[]` をバウンディングボックスで正規化（0–100 座標系へ）
2. 各収録文字とマッチング:
   - 楔本数の差でまず足切り
   - 入力楔と手本楔の対応付けを貪欲法（近い順）で行い、位置・角度・種類の一致度からコストを計算
3. スコア上位5件を候補として表示（文字名・音価・意味・Unicode 文字）

```ts
function recognize(input: Wedge[], signs: Sign[]): Array<{ sign: Sign; confidence: number }>;
```

複数文字の連続書きは MVP では対象外（1文字ずつ認識）。第2弾で楔の x 座標クラスタリングによる文字分割を導入する。

**将来**: フォント描画＋データ拡張で学習した軽量 CNN（ONNX Runtime Web）に置き換え、フリーハンド描画の認識にも対応。

### 5.4 F4: 日本語 → 楔形文字変換

日本語のかなを、アッカド語音節文字の**音価が近い文字**に転写する（学術的な翻訳ではなく音写であることを UI に明記）。

**パイプライン**:

```
入力（漢字かな混じり文）
  → かなに正規化（漢字はユーザーに読みを入力してもらう or MVP はかな入力のみ）
  → モーラ分割（きゃ・っ・ん などの特殊モーラ処理）
  → モーラ → 文字ID のマッピングテーブル参照
  → Sign 列 → Unicode 文字列 + 楔グリフ表示
```

**マッピング方針**（`src/data/kana2sign.json`）:
- 基本: 1モーラ = 1 CV 音節文字（か → KA 𒅗、み → MI 𒈪 …）
- アッカド語にない音の近似規則を定義:
  - ん → 直前母音に応じた VC 文字（an/in/un/en）
  - っ → 次の子音の重複として無視 or 小休止記号なしで省略
  - つ → TU、ふ → PU など近似
  - 濁音・半濁音: アッカド語は b/d/g/z を区別できるのでそのまま対応可
- 変換結果には各文字の下に「音価ラベル」を表示し、どう読まれるかを可視化

**出力**: テキストコピー（Unicode）、画像保存、「この文字を練習する」リンクで習字モードへ接続。

## 6. 画面構成

```
/                ホーム（4機能への導線 + 進捗サマリ）
/practice        習字: 文字一覧（レベル・習得状況フィルタ）
/practice/:id    習字: 練習画面
/canvas          自由書きキャンバス
/read            読み取り（キャンバス + 候補表示）
/convert         日本語→楔形文字変換
/signs/:id       文字詳細（辞書ページ: 読み・意味・書き順アニメーション）
```

## 7. ディレクトリ構成

```
src/
  components/
    WedgeGlyph.tsx        # Wedge[] → SVG 描画（全機能で共用）
    WedgeCanvas.tsx       # 楔スタンプ入力キャンバス（共用）
    StrokeGuide.tsx       # 習字用ガイド表示
  features/
    practice/             # F1 習字
    canvas/               # F2 自由書き
    recognize/            # F3 読み取り
    convert/              # F4 変換
  lib/
    wedge.ts              # Wedge 型・幾何計算・正規化
    scoring.ts            # なぞり判定（scoreWedge）
    recognizer.ts         # 認識アルゴリズム（recognize）
    kana.ts               # かな正規化・モーラ分割
    transliterate.ts      # モーラ→Sign 変換
    progress.ts           # localStorage 進捗管理
  data/
    signs.json            # 文字定義（楔分解データ）
    kana2sign.json        # かな→文字マッピング
  pages/                  # ルーティング単位のページ
```

ロジック（`lib/`）はすべて DOM 非依存の純関数とし、Vitest でユニットテストする。

## 9. リスクと対策

| リスク | 対策 |
|--------|------|
| 楔分解データの作成コストが高い（既存 DB がない） | 内部エディタを最初に作る。第1弾は60字に絞る |
| 端末に楔形文字フォントがない | Noto Sans Cuneiform を Web フォントとしてサブセット配信 |
| 日本語→楔形文字の音写に「正解」がない | 近似規則を明文化し、UI に「音写であり翻訳ではない」旨を表示 |
| スマホの小さい画面で細かい楔が打ちにくい | キャンバスのズーム、楔スナップ、頭位置の吸着許容を広めに設定 |
